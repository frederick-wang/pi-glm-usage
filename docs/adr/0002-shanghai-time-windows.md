# 0002 — Ship v1 bilingual-ready but English-only

The repo is public ecosystem tooling: all eight surveyed pi extension repos are English-first, and the pi package gallery and npm audience are international. README, footer text, `/glm-usage` report labels, and commit messages are English-only for v1. Footer text is language-neutral (`GLM 5h 34%~·M 12%`). A Chinese README section can be added later if demand appears — cheap to bolt on, expensive to maintain from day one, so we don't.
